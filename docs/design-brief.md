# 设计简报：在 iPhone 上使用自己 Mac 的终端（PWA）

> 给 Claude Design 的输入。请按第 7 节的交付格式出稿。

## 0. 一句话

在 iPhone 上像用原生 App 一样使用自己 Mac 的终端。网站在 `term.dkz12345.com`，用户把它「添加到主屏幕」后全屏运行。

## 1. 使用者与场景

**唯一用户**：我自己。开发者，中文母语。Mac 上日常用 Ghostty 终端，配色 Catppuccin Mocha，字体 Menlo，提示符是 starship。

**典型场景**

1. 躺着或在路上，看一眼 Mac 上跑着的构建和日志，敲几条短命令（`git status`、`npm test`、`ls`）。
2. 在手机上继续和 Claude Code（命令行版）对话：输入中文长段落，确认工具调用（按 `1`、`2`、`Esc`、`⇧Tab`）。
3. 锁屏收到推送「命令跑完了」或「Claude Code 等你确认」，点开直接落在对应会话。
4. 切到别的 App、进电梯、Wi-Fi 换蜂窝之后再回来，会话无感恢复，内容一行不丢。

**平台**：iPhone 竖屏为主（基准 390×844，兼顾 375 和 430 宽），横屏其次。形态是 iOS「添加到主屏幕」后的独立窗口，没有 Safari 地址栏。iPad 以后再做。

## 2. 体验原则

1. **终端内容优先**。键盘弹起后，iPhone 竖屏只剩约 330pt 给「终端 + 快捷键栏」，每一行都珍贵。顶栏之类的界面元素在键盘弹起时要能压缩或收起。
2. **延迟看得出来，但不打扰**。服务器在日本，每个按键的回显约 250ms，偶尔丢包会卡一下。缓解延迟主要靠撰写栏：在本地编辑整行，一次发出。连接状态要轻量可见。
3. **手势符合 iOS 直觉**。上下滑回看历史，捏合改字号，长按选文字，左右轻扫切会话。不能和系统手势冲突：屏幕左边缘是返回，底部是 Home 条。
4. **和 Mac 上的终端一个味道**。默认 Catppuccin Mocha 配色 + Menlo 字体（第 6 节）。
5. **公开页面保持中性**。登录页和配对页上，可见文字和页面标题里都不能出现「终端 / 远程 / 控制 / shell / Mac / 命令」这类描述用途的词。我之前的另一个站点就因为这个被 Google Safe Browsing 标成了欺骗网站。登录后的界面不受此限。

## 3. 技术约束

- **终端网格由 xterm.js 用 canvas 渲染**。设计只需要规定字体、字号范围、行高、内边距、配色（16 色 ANSI + 前景、背景、光标、选区）。网格内部放不了自定义 UI 元素。所有浮层（胶囊、横幅、HUD）都在网格之上另起一层。
- **字宽参考**：Menlo 13px，竖屏约 48 列；11px 约 57 列；横屏 13px 约 105 列。Claude Code 和 starship 的右对齐时间在 48 列下会折行，属于正常现象。
- **字体**：终端用 Menlo（iOS 自带），中文回退 PingFang SC。界面用系统字体（`-apple-system` / PingFang SC）。**不能引用任何外部资源**（CSP 只允许本站），不要 Google Fonts，不要 CDN。确实需要特殊字体时，提供可自托管的 woff2，体积尽量小。
- **图标**：内联 SVG。
- **iOS 安全区**：顶部有灵动岛或刘海，底部有 Home 指示条。键盘弹起时，布局跟随可视区域收缩，不能被键盘挡住。键盘高度按约 336pt 预留，中文输入法的候选栏会更高。
- **深色为主**。v1 只做深色界面即可，浅色终端配色作为可选主题出现在设置里。
- **触控目标 ≥ 44pt**。快捷键栏的键可以窄一些，但高度 ≥ 40pt。
- **界面文案用简体中文**。
- **产品名待定**：请提 3 个中性候选（短英文词或两个音节，不暗示「终端」或「远程控制」），用于主屏幕图标名、登录页和 PWA 标题。

## 4. 主要流程

```
首次使用
  Mac 菜单栏程序显示配对二维码
    → iPhone 相机扫码，Safari 打开「配对页」
    → 点「创建通行密钥」→ 面容 ID
    → 配对完成 → 引导「添加到主屏幕」
    → 从主屏幕图标打开 → 登录页 → 面容 ID → 新建第一个会话

日常使用
  点主屏幕图标
    → 凭据在有效期内：直接回到上次的会话，内容就是离开时的样子（期间的新输出也在）
    → 凭据过期：解锁页 → 面容 ID → 回到会话

推送
  锁屏通知「完成 · npm run build」→ 点开 → 直接进入那个会话

断线
  切后台再回来、网络切换 → 顶部细条「正在重新连接…」（内容保留，略微变暗）→ 1–2 秒内恢复
  Mac 合盖睡眠或菜单栏程序没开 → 「电脑离线」状态
```

## 5. 页面与组件（每项请画出列出的全部状态）

### 5.1 登录页 `LoginPage`（公开）

- **元素**：产品标识；主按钮「使用通行密钥登录」；次要链接「还没有在这台设备上配对？」，点开是一小段说明（在电脑上打开配对二维码，用相机扫描）。
- **状态**：默认；验证中（系统面容 ID 弹层出现时，按钮显示加载）；失败（取消或未识别，可重试）；尝试次数过多（显示倒计时）；网络错误。
- **约束**：文案中性（见原则 5）。

### 5.2 配对页 `PairPage`（公开，扫码进入）

- **步骤**：
  1. 说明 + 按钮「创建通行密钥」
  2. 系统面容 ID
  3. 完成：「配对完成」+ 添加到主屏幕的分步引导（Safari 分享按钮 → 添加到主屏幕 → 从主屏幕打开）
- **错误状态**：二维码已过期或已被使用；设备离线；用户取消；当前浏览器不支持通行密钥（比如在微信里打开，需要引导去 Safari）。

### 5.3 主屏幕引导 `InstallGuide`

- 配对完成时出现，设置里也能再次打开。
- 在 Safari 标签页（而不是主屏幕 App）里登录后，顶部有一条可关闭的提示条：「添加到主屏幕后可以全屏使用并接收通知」。

### 5.4 终端主界面 `TerminalScreen`（核心，重点设计）

**顶栏 `TopBar`**

- 会话标题：前台进程 + 目录名，例如 `claude · mac-remote`。点击打开会话切换器。
- 连接状态点：在线 / 重连中 / 离线，旁边可选显示往返延迟（如 `238ms`）。
- 「⋯」菜单：新建会话、选择文本、字号、设置、立即锁定。
- 键盘弹起时压缩成更薄的样式，或完全收起。

**终端区 `Terminal`（xterm 网格 + 浮层）**

- 回看中：离开底部时出现胶囊「↓ 回到底部 · 12 行新输出」。
- 重连中：内容保留，轻微变暗，顶部细条「正在重新连接…」。
- 进程已退出：底部内联横幅「会话已结束（退出码 0）」+「重新开始」「关闭」。
- 响铃：顶栏或屏幕边缘轻闪一下。
- 捏合缩放时：居中 HUD「14 pt · 48×22」。

**快捷键栏 `KeyBar`（贴在系统键盘上方）**

- 必须有：
  - `Esc`、`Tab`
  - `Ctrl`、`⌥`：粘滞键，点一下后下一个键带修饰，双击锁定。需要三种视觉状态：关 / 一次性 / 锁定。
  - 方向键 ↑ ↓ ← →
  - 常用符号 `|` `/` `-` `~` `` ` ``
  - 给 Claude Code 用的快捷键：`⇧Tab`、`Ctrl+C`
- 键数超过一屏宽，请决定是左右滑动还是分页。
- 建议（可采纳可替换）：方向键做成「触控板」，按住拖动连续发送方向键；长按某个键弹出备选符号，像 iOS 键盘那样。
- 键盘收起时：底部只留一个小按钮或薄条，用来唤起键盘或撰写栏。

**撰写栏 `ComposeBar`（和「直接输入」两种模式切换）**

- **直接模式**：每个按键立刻发给终端。vim、输密码、Claude Code 的单键选择都需要这个模式。
- **撰写模式**：原生多行输入框 + 发送按钮。
  - 回车 = 发送（内容 + 回车）；换行用另一种方式（比如换行按钮）。
  - 支持粘贴、听写、中文输入法。
  - 能调出最近发送过的内容（历史）。
  - 状态：空、输入中、多行展开、发送中、发送失败。
- 当前是哪种模式要一眼看得出，单手能切换。

**危险命令确认 `ConfirmSheet`**

- 撰写模式发送前，命中规则时弹出。例如：「这条命令会关闭 Wi-Fi，电脑会断开连接」[取消] [仍然发送]。

**选择文本 `SelectTextSheet`**

- 长按终端，或从菜单进入。
- 把屏幕和回看内容以等宽文本全屏展示，用 iOS 原生的选择手柄选中。
- 按钮：「复制全部」「复制上一条命令的输出」；关闭后回到终端。

### 5.5 会话切换器 `SessionSwitcher`

- **形式**：由设计决定（底部 sheet、下拉面板或卡片网格都可以）。
- **每个会话卡片**：
  - 标题（前台进程）
  - 工作目录（缩略）
  - 最后一行输出预览（等宽，单行截断）
  - 最后活动时间
  - 状态徽标：运行中 / 有新输出 / 响铃 / 已结束
  - 当前会话高亮
- **操作**：
  - 点击切换
  - 左滑关闭（会结束会话里的进程；有前台程序在跑时需要二次确认）
  - 重命名
  - 「新建会话」（可选起始目录：主目录或最近用过的目录）
- **空状态**：还没有会话时，只有一个大号「新建会话」。
- **终端界面里左右轻扫切换相邻会话**：需要过渡动画和位置指示（比如小圆点）。注意避开屏幕左边缘的系统返回手势。

### 5.6 电脑离线 `OfflineState`

- 「电脑离线」+ 最后在线时间 + 可能原因（合盖睡眠 / 菜单栏程序没运行 / 网络问题）+「重试」。
- 会话列表以缓存的灰色状态显示。

### 5.7 解锁页 `LockScreen`

- 登录后凭据过期或手动锁定时出现。
- 模糊或遮住终端内容，显示「验证身份以继续」+ 面容 ID 按钮。

### 5.8 设置 `Settings`

- **外观**：
  - 终端配色：默认 Catppuccin Mocha，另给 2–3 个备选，比如 Catppuccin Latte（浅色）、纯黑 OLED。以预览卡形式展示。
  - 字号
  - 光标样式：块 / 竖线 / 下划线，外加闪烁开关
  - 快捷键栏开关
- **通知**（按状态设计）：
  - 未添加到主屏幕：显示引导
  - 未授权：「开启通知」按钮
  - 已拒绝：说明如何去系统设置里打开
  - 已开启：分类开关，包括「长命令完成」（阈值如 ≥30 秒）、「终端响铃」、「Claude Code 需要确认」；另有「发送测试通知」
- **安全**：
  - 已配对的通行密钥列表（名称、创建时间、最后使用），可移除
  - 「立即锁定」
  - 自动锁定时间
- **连接**：电脑状态、往返延迟、版本号
- **退出登录**

### 5.9 系统通知文案

请给出文案规范（长度、时间格式、截断规则）。示例：

- 完成：标题「完成 · npm run build」，正文「用时 3 分 12 秒 · mac-remote」
- 失败：标题「失败 · npm test」，正文「退出码 1 · 用时 42 秒」
- 响铃：「会话 claude 响铃了」
- Claude Code：标题「Claude Code 需要你确认」，正文取 Claude 的提示原文

### 5.10 PWA 资源

- 启动背景色、`theme-color`、状态栏样式（`black-translucent`）。

## 7. 交付格式

- **画板**：每个页面或组件一个画板，覆盖第 5 节列出的所有状态。基准尺寸 iPhone 390×844。关键页面（终端主界面、撰写栏、快捷键栏）再加两块：键盘弹起状态、横屏。
- **代码**：静态 HTML + CSS，不用前端框架。设计令牌写成 CSS 自定义属性（`--color-*`、`--space-*`、`--radius-*`、`--font-*`），我会直接接入真实逻辑。
- **终端区域**：稿子里用静态等宽文本模拟（第 6 节配色），接入时替换成 xterm.js。
- **组件命名**：沿用本文的英文名（`TopBar`、`KeyBar`、`ComposeBar`……），方便对照接入。
- **资源**：图标用 SVG；不引用任何外部 CDN 或字体服务。

## 9. 实现备注（功能版已经做好，设计请按这些约束来）

功能版的界面是临时的（`web/app/`、`web/public/`），逻辑和外观是分开的，接入设计稿时只替换 HTML/CSS。下面几点已经定下来，会影响设计：

- **暂定名 Harbor**：代码里的占位名，等你从候选名里选定后统一替换。
- **键盘弹起时终端不改尺寸**：终端保持键盘收起时的完整行数，整体上移，让光标露出来（避免每次弹键盘都让 shell 和 Claude Code 重绘）。所以键盘弹起时，终端最上面几行会滑到顶栏下面。顶栏可以考虑半透明加模糊，或者键盘弹起时只剩很薄一条。
- **底部停靠栏**的结构是 `[直接/撰写 切换] [可横向滑动的快捷键] [收起/弹出键盘]`，撰写模式下输入框出现在这一行上方。
- **快捷键栏的键**（从左到右）：esc、tab、ctrl、⌥、← ↑ ↓ →、⇧tab、^C、| / - ~ `、home、end、pgup、pgdn、粘贴。ctrl 和 ⌥ 有三种状态：关、一次性、锁定。
- **会话卡片能拿到的数据**：自定义名称、程序设置的标题、前台进程名（如 `claude`、`vim`、`zsh`）、工作目录、最后一行输出预览、最后输出时间、正在运行的命令原文、上一条命令的原文/退出码/耗时、会话结束时的退出码或信号。
- **连接状态**有这几种：连接中、重连中、握手中、在线、电脑离线、需要验证身份。
- **终端字体**用系统 Menlo 渲染（DOM 渲染器），中文和 emoji 走系统字体，不需要额外字体文件。
- **设置里已有的分区**：外观（字号）、通知（按添加到主屏幕/授权状态分支）、设备（通行密钥列表、移除、生成配对链接）、安全（立即锁定、退出登录）、关于（电脑名、往返延迟、版本）。
